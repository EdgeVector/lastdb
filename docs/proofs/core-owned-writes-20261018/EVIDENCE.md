This directory separates exact operational results from timing results.
The [before identity](before-identity.json) names accepted main `011b29f3…` and executable `a0ad6190…`.
Each candidate identity names a separate source freeze and executable.
An unbuilt source freeze is not an executed program.

The first `be38c44c…` discovery retains its private executable and exact 1,926 source input hashes.
Its full product source bytes do not remain in a separate immutable Git tree or archive.
The source changes before that archive exists. This is an explicit diagnostic reproduction limit.
The final timing candidate must retain an immutable committed source tree before its release build.

The [discovery report](DISCOVERY.md) preserves driver assumptions, reference failures, candidate failures, and diagnostics.
The [route matrix](ROUTES.md) separates typed logical routes, disk-first system routes, source review, and runtime gaps.
The [result report](RESULTS.md) states the exact comparison and its limits.

Shared reproducible drivers, concise identities, result summaries, and cleanup receipts belong in Git.
Raw generated requests, values, logs, duplicate source copies, and duplicate per-run identities stay local under the existing ignore rules.
The final `evidence-index.json` records their exact relative paths, sizes, hashes, and disposition.
Its `local_root` field identifies this local worktree. A link to an ignored raw file requires that local evidence.
The index excludes its own generated outputs to prevent a self-hash cycle.

Older driver identities and executed source copies stay unchanged.
