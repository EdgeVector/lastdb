Native memory relief still called the retired storage cache. Named Purge also lost its data scope in several steps. This change uses the current core model for memory relief and retains the requested database through erasure.

The shared rules now cover key validation, related molecules, ordered reads, and reference proof:

- Flush accepted writes before explicit memory relief. Purge only clean records without a call hold. Report separate memory allowances and incomplete relief.
- Share equal complete atoms while retaining every original allocation and its write owner. Remove obsolete cache controls and reservation-count polling.
- Refuse duplicate source identities and conflicting key-field values before source preparation. Preserve empty keys and spaces in related molecules. Remove redundant ordinary CAS locks; retain aggregate guards.
- Honor Purge conditions and scoped must-exist checks. Remove schema markers through their proper namespace and source schema in the same native transaction.
- Use one home-wide reference completion proof while reference data remains scoped. Remove the retired v1-empty logical fallback.
- Correct descending equal-range pages, tombstone-inclusive page selection, and maximum-Unicode prefixes. Use one encoding in warm range windows and preload selected keys for counts.
