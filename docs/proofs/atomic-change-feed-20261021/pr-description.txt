Default writes can return before local disk completion. Every native request now waits for its required disk sequence, including default and queued caller inputs.

The core also stores each change notice and its feed position with the corresponding data. The separate Mini notice queue is removed. The data and its notices share one native commit. This does not mean one total disk write per HTTP call. Durable author-clock reservations remain separate. Mixed mutation and aggregate requests retain their required phases. Notices describe accepted changes; apps read current values after a notice.

The earlier cleanup removes obsolete memory-ack controls, repeated namespace flushes, redundant receipt guards, and full-body copies used only for JSON size.
