## Generated data and measurement

Each home starts empty and receives a separate build from the same generated input.
No database or identity is copied.
The input has 4,096 records in collection `Layer2Receipt`, with fanout 1.
Keys use `generated` plus NUL plus `record-N`, where N contains six decimal digits.
The ordinary body is 32 concatenated SHA-256 values of `Layer2-Oct16:N:chunk`, with chunk from 0 through 31.
Every 997th body is empty. Every 251st key is a tombstone.
The input SHA-256 is `57fe5d39ee8400b1bc3fe36f96a660a2c621b64dae0cee6b1579b9c90598f196`.

Read sizes are 1, 16, 64, and 256 coordinates.
Each case has 11 repeats. Baseline and candidate order alternates on each repeat.
Each product command opens a fresh read call. Its filesystem cache state remains unknown.
There are three request patterns:

- Contiguous: keys 1024 through `1024 + size - 1`, in the same pack file.
- Scattered: key `(73 + 37 * slot) mod 4096`, across the same packed object.
- Duplicates: repeated coordinates 1111, 1112, 1111, and absent key 999999.

Write sizes are 1, 16, 64, and 256 complete stored operations.
Each size and pattern receives its own fresh pair of homes and seven complete writes.
Distinct writes address keys from 2048. Repeated writes address key 2048 for every operation.
All journal operations remain present even when the last operation supplies the final locator.
After each seven-write case, a fresh command reads all 4,096 keys.
Every returned byte and absence matches the generated input plus the accepted writes.

The task and both peers reserve a quiet host interval for these calls.
The recorded command time includes the native command's work before its final output print.
It is not a device latency or a node request latency.
The p95 uses the nearest rank. With 11 or seven samples, it is the largest observed value.

## Regressions and limits

The distinct one-operation write median increases by 21.6 percent.
The distinct 16-operation write p95 increases from 191.957 to 354.518 ms.
These are real observations; the source checks do not remove them.
The repeated one-operation median improves, and write times vary substantially in both programs.
Filesystem barrier variation is a possible cause. These receipts do not establish that cause.
Repeat small-write measurements with more samples after the generation guard and complete candidate integrate.
