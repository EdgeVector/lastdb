This PR stays a draft because performance remains unresolved. Four alternating runs compare both releases with explicit durable requests, fresh generated data, Hash and HashRange, and batches of 1, 32, and 128. They contain 20,608 measured mutations. The candidate records 13–60 percent lower aggregate throughput. Compiler and other database jobs overlap these shared-host runs. These results establish no speed gain or isolated throughput maximum. The optional broader follow-on is interrupted and retained as partial evidence.

The read timer includes JSON decode. These are shared-host observations, not isolated source-effect estimates.
