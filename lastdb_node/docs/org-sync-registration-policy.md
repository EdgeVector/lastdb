# Retired Org cloud routes

The Org cloud registration, target, authority, and member grant routes are retired.
The client does not send Org cloud sync work.

Local Org databases, schema catalogs, permissions, and encryption remain available.
Existing Org target records remain readable as passive data.
The retirement does not delete local Org records or change their encryption.
V2 backup copies the native files without an Org cloud transfer.
